# Experiments

Every substantial Lab effort has one durable experiment record named
`NNNN-short-title.md`, where `NNNN` is the four-digit portion of its stable
`EXP-NNNN` identifier. Numbers are allocated when a proposal opens and are never
reused.

Experiment status follows:

```text
Proposed -> Active -> Concluded -> Promoted
    |          |          |
    v          v          v
 Abandoned  Abandoned  Archived
```

`Promoted` identifies the destination issue, RFC, or release; it does not make
the Lab artifact itself stable. Copy
[`0000-template.md`](0000-template.md) to begin a record.
